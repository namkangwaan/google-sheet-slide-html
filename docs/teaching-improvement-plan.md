# แผนปรับปรุงสื่อ Google Sheets สำหรับเรียนด้วยตนเอง

จัดทำก่อนเริ่มแก้ไข: 24 กันยายน 2026

## เป้าหมายและขอบเขต

ให้นักเรียนเปิดเว็บสาธารณะแล้วรู้ว่าจะเริ่มตรงไหน เปิดแบบฝึกอย่างไร ฝึกและตรวจความเข้าใจได้ด้วยตนเอง และทราบเกณฑ์ส่งงาน ใช้ภาษาไทยเป็นหลักพร้อมชื่อฟังก์ชันภาษาอังกฤษ คงรูปแบบสไลด์สีเขียว/กรมท่าและเนื้อหาขั้นสูงสำหรับผู้เรียนที่พร้อมแล้ว

## ขั้นตอนดำเนินการ

1. **ตรวจและแก้ความถูกต้อง** — แก้ REGEXTRACT เป็น REGEXEXTRACT, จำนวนเซลล์ใน COUNT, ข้อความอ้างสถิติที่ไม่มีแหล่งข้อมูล, Tables, IFERROR และข้อจำกัดของ Regex; ตรวจสูตร/ผลลัพธ์อื่นที่เกี่ยวข้อง
2. **เริ่มเรียนและเส้นทางเรียน** — เพิ่มผลลัพธ์การเรียนรู้ อุปกรณ์ที่แนะนำ วิธีดาวน์โหลด/นำเข้า/บันทึกเป็น Google Sheets การตั้ง Locale/Time zone วิธีใช้สื่อและส่งงาน แบ่งบทพื้นฐานกับบทต่อยอดและแสดงข้อกำหนดก่อนเรียน
3. **ทักษะพื้นฐานและกิจกรรม** — เพิ่มเซลล์/ช่วงข้อมูล ตารางที่ดี การอ้างอิงสัมพัทธ์และสัมบูรณ์ การตรึง/เรียง/กรอง Dropdown/Checkbox, Conditional formatting, กราฟและ Pivot table พร้อมโจทย์ คำใบ้ เฉลยและคำถามตรวจความเข้าใจ ใช้ชุดข้อมูลห้องเรียนที่พิมพ์ตามได้
4. **ลำดับและการประเมิน** — เรียง Regex พื้นฐานก่อน Workshop; เพิ่มแนวทางแก้ error และตรวจข้อมูล; เพิ่ม Capstone ที่ระบุผลงาน เกณฑ์ให้คะแนนและวิธีส่ง พร้อมเฉลยแบบเปิดดูเองได้โดยไม่ต้องติดตั้ง Apps Script
5. **แบบฝึกและเฉลย** — ตรวจไฟล์ XLSX จริงเทียบกับ generator และ Apps Script โดยเฉพาะแถวเริ่มข้อมูลหลังหัวเรื่อง; ปรับเฉลยและคำอธิบายให้ตรงกับข้อมูลจริง ไม่ใส่สูตรเฉลยทับช่องคำตอบของผู้เรียน
6. **ระบบนำทางและตรวจสอบ** — นับสไลด์จาก DOM ใช้ลิงก์ประจำสไลด์ที่คงที่ สารบัญต้องตรงกับลำดับใหม่ รองรับการพิมพ์คำตอบโดย hotkey ไม่แทรก ตรวจหน้าจอคอมพิวเตอร์/มือถือ การคัดลอกสูตรและดาวน์โหลด

## เกณฑ์เสร็จงาน

- เปิดหน้าแรกแล้วเริ่มเรียนหรือเลือกบทได้ และรู้วิธีเปิดแบบฝึกส่วนตัว
- ทุกหัวข้อใหม่มีกิจกรรมหรือจุดตรวจความเข้าใจ พร้อมเหตุผลของเฉลย
- สไลด์ประเมินผลและหน้าสรุปเข้าถึงได้จากปุ่มนำทาง สารบัญ และลิงก์ตรง
- สูตรตัวอย่างและคำตอบที่แก้มีการตรวจเทียบข้อมูล; ระบุชัดว่าจุดใดยังไม่ได้ทดสอบใน Google Sheets จริง
- `pnpm build` ผ่าน; ทดสอบการนำทาง ช่องคำตอบ การเปิดคำใบ้/เฉลย และดาวน์โหลดในเบราว์เซอร์

## ข้อสมมติ

ผู้เรียนเป็นผู้เริ่มต้นที่ใช้งานเว็บได้ ยังไม่กำหนดระดับชั้นหรือเวลาคาบ จึงแบ่งเป็นบทสั้นที่เลือกเรียนได้ ใช้ข้อมูลสมมติ ไม่ต้องมีระบบบัญชีหรือฐานข้อมูลในเว็บไซต์ งานรอบนี้เตรียมเว็บให้พร้อมเผยแพร่ แต่ไม่รวมการนำขึ้น hosting
