Formulas

Anatomy of a Google Sheets Formula

ส่วนประกอบพื้นฐานของสูตรคำนวณ: เครื่องหมายเท่ากับ ฟังก์ชัน และอาร์กิวเมนต์

=SUMIFS(C2:C100, A2:A100, "North")
=

Assignment Trigger: Tells Sheets calculation begins (จุดเริ่มต้นการคำนวณ)

SUMIFS

Function Keyword: Built-in calculation engine (ชื่อฟังก์ชันมาตรฐาน)

( ... )

Arguments: Target ranges, criteria, conditions (พารามิเตอร์และเงื่อนไข)

Remember: Every formula must begin with an equal sign (=)

Syntax Rules

Critical Formula Syntax & Separators

กฎเกณฑ์สัญลักษณ์ตัวคั่น และรูปแบบการอ้างอิงที่ต้องจำขึ้นใจ

,

Comma Separator

Separates individual arguments inside functions.

คั่นระหว่างอาร์กิวเมนต์ในสูตร

:

Colon Range

Defines contiguous cell boundaries start to end.

ระบุช่วงเซลล์ต่อเนื่อง (A1:B10)

$

Dollar Anchor

Fixes row or column coordinates when dragging.

ตรึงตำแหน่งเซลล์ไม่ให้เลื่อน ($A$1)

""

Text Quotes

Encloses string literals to prevent name collisions.

ครอบข้อความเพื่อป้องกัน error

Tip: Press F4 while selecting a cell coordinate to quickly cycle $ dollar anchors.

Data Modeling

Dimensions vs. Measurements (Metrics)

การจำแนกความแตกต่างระหว่างมิติข้อมูล (คุณภาพ) และตัวชี้วัด (ปริมาณ)

DIMENSION

Qualitative Attributes

Categories used to slice, dice, and group data:

  • Customer Region: Bangkok, Chiang Mai, Phuket
  • Product Category: Electronics, Office Supplies
  • Transaction Date: 2026-09-20
  • Employee Department: Engineering, Sales, HR

มิติเชิงคุณภาพ ใช้จัดกลุ่ม แจกแจง และแบ่งย่อยข้อมูลสำหรับวิเคราะห์

MEASUREMENT / METRIC

Quantitative Numbers

Numerical figures you aggregate and compute:

  • Total Revenue: ฿1,250,000
  • Units Sold: 4,200 items
  • Discount Amount: ฿12,400
  • Profit Margin: 24.5%

ค่าตัวเลขทางคณิตศาสตร์ สามารถบวก ลบ คูณ หาร และหาค่าเฉลี่ยได้

Golden Rule: You group BY dimensions, and you calculate ON metrics.

Dimensions

Working with Dimensions in Formulas

ฟังก์ชันที่ใช้จัดการกับมิติข้อมูล: การแจงค่าไม่ซ้ำ การนับความถี่ และการกรอง

=UNIQUE(A2:A)

Extracts distinct categories (ดึงค่าที่ไม่ซ้ำกัน)

=COUNTIF(A2:A, "Bangkok")

Counts frequency by dimension (นับจำนวนรายการตามมิติ)

=FILTER(B2:B, A2:A="Online")

Segments dataset by group (กรองข้อมูลตามกลุ่ม)

Dimensions define the grouping keys in charts and pivot summaries.

Number

Aligns Right

1500 | 45.2%

Text (String)

Aligns Left

"Product A"

Date & Time

Serial number + time fraction

2026-09-20

วันและเวลา ในรูปแบบเลขลำดับนับต่อจากอดีต

Boolean

Aligns Center

Data Types

Number Type: Raw Values vs. Display Formats

ทำความเข้าใจระหว่างค่าดิบ (Raw Value) และรูปแบบการแสดงผล (Format)

The Golden Principle

Formatting only changes the visual presentation, not the underlying number.

Raw Stored: 0.25 ➔ Formatted View: 25.0%
Raw Stored: 1200 ➔ Formatted View: ฿1,200.00

การจัดฟอร์แมตเปลี่ยนเฉพาะสิ่งที่สายตาเห็น แต่ค่าจริงที่สูตรนำไปคำนวณยังคงเดิม

Helpful Number Functions

=ROUND(A1, 2) ปัดเศษทศนิยม 2 ตำแหน่ง
=INT(A1) ปัดเศษลงเป็นจำนวนเต็ม
=MOD(A1, B1) หาเศษเหลือจากการหาร
Shortcuts: Ctrl + Shift + 4 applies Currency; Ctrl + Shift + 5 applies Percentage.

Data Types

Text Type: Strings & Text Cleaning Functions

การจัดการข้อความ การเชื่อมคำ และการทำความสะอาดข้อมูลตัวอักษร

Concatenate Strings

=A1 & " " & B1

Merges first and last names together with space.

เชื่อมต่อข้อความเข้าด้วยกัน

Trim Whitespace

=TRIM(A1)

Removes accidental leading and trailing spaces.

ลบช่องว่างส่วนเกินหัวท้าย ป้องกัน lookup หาไม่เจอ

Substring Extraction

=LEFT(A1, 4)

Extracts first 4 characters (e.g. "SKU-").

ตัดตัวอักษรเฉพาะส่วนหน้า หรือส่วนท้ายด้วย RIGHT()

ถ้าค้นหาไม่พบ ให้ตรวจช่องว่าง ชนิดข้อมูล และช่วงค้นหาก่อนใช้ TRIM หรือแก้สูตร

Data Types

Date & Time: Serial Number Mechanics

เบื้องหลังข้อมูลวันที่: ทุกวันคือตัวเลขจำนวนเต็มที่นับต่อจากอดีต

Dates are Integers Behind the Scenes

In Google Sheets, Day 1 is December 31, 1899. Adding 1 to a date increases it by exactly one day. Time is stored as decimals (0.5 = 12:00 noon).

=TODAY() + 7 (Exact date 1 week in future)

วันที่จะถูกแปลงเป็นตัวเลขเสมอ ทำให้เราสามารถบวก/ลบจำนวนวันได้โดยตรง

Essential Date Functions

=YEAR(A1) สกัดเฉพาะเลขปี ค.ศ.
=MONTH(A1) สกัดลำดับเดือน (1 - 12)
=EOMONTH(A1, 0) หาวันสิ้นสุดของเดือน
=DATEDIF(A1, B1, "D") คำนวณผลต่างระยะห่างเป็นวัน
Function note: =NOW() gives current date & timestamp; =TODAY() gives current date only.

Data Types

Boolean Logic: Conditional Decision Making

การควบคุมตรรกะการตัดสินใจด้วยค่าความจริง TRUE และ FALSE

IF Branching

=IF(C2>=50, "Pass", "Fail")

Executes branch condition based on TRUE or FALSE.

กำหนดผลลัพธ์ตามเกณฑ์ ผ่าน/ไม่ผ่าน

AND Gate

=AND(A2>18, B2="TH")

Requires ALL evaluated criteria to be TRUE simultaneously.

จริงเมื่อทุกเงื่อนไขถูกต้องพร้อมกัน

OR Gate

=OR(A2="VIP", B2>10000)

Returns TRUE if ANY single criteria evaluates TRUE.

จริงเมื่อมีเงื่อนไขใดเงื่อนไขหนึ่งตรงตามเกณฑ์

In mathematical calculations: TRUE equals 1, and FALSE equals 0.

Data Structure

Understanding Data Range & Addressing

ขอบเขตข้อมูล (Data Range) และรูปแบบการอ้างอิงตำแหน่งในตาราง

A1:B10

Bounded rectangular block of 20 cells (ช่วงสี่เหลี่ยมระบุหัวท้ายชัดเจน)

A2:A

Open-ended infinite range auto-expanding to bottom (ช่วงเปิดรับข้อมูลแถวใหม่เสมอ)

Sales!A1:C20

Cross-sheet reference using exclamation mark (การอ้างอิงข้ามชีทงาน)

Remember: Use open-ended ranges (A2:A) for Google Forms and live transaction sheets.

Named Ranges

Defined Names: Enhancing Formula Readability

การตั้งชื่อช่วงเซลล์ (Named Ranges) เพื่อเพิ่มความเข้าใจและลดความผิดพลาด

TRADITIONAL COORDINATES
=SUM(Sheet1!$C$2:$C$150)

Cryptic coordinates that are difficult to audit, decipher, and maintain across business teams.

การอ้างอิงพิกัดเซลล์แบบเดิม อ่านยาก และตรวจสอบสูตรลำบาก

DEFINED NAMED RANGE
=SUM(Total_Revenue)

Human-readable, self-documenting syntax. Works across all sheets without manual sheet prefix.

การตั้งชื่อสื่อความหมายชัดเจน สูตรเข้าใจง่ายและเป็นระเบียบ

Naming rules: Must not contain spaces, start with letters or underscores, and cannot conflict with cell names like A1.

Lookup Functions

VLOOKUP: Vertical Table Lookup

การค้นหาข้อมูลในแนวตั้งจากคอลัมน์ซ้ายสุดเพื่อดึงค่าในคอลัมน์เป้าหมาย

=VLOOKUP(search_key, range, index, [is_sorted])

search_key: ค่าที่ต้องการค้นหา (เช่น A2)

range: ตารางอ้างอิง คอลัมน์แรกต้องมี search_key เสมอ

index: ลำดับเลขคอลัมน์ที่ต้องการดึงค่ากลับมา (1, 2, 3...)

is_sorted: ใส่ FALSE หรือ 0 เสมอเพื่อหาแบบตรงกันเป๊ะ

CAUTION

ข้อควรระวัง

  • ดึงข้อมูลไปทางซ้ายไม่ได้
  • แทรกคอลัมน์แล้วเลข index จะเพี้ยน
  • ลืมใส่ FALSE อาจได้คำตอบผิด
Always remember: VLOOKUP searches from left to right only.

Practical Workshop

VLOOKUP in Action: Student Exercise

ภาพจำลองการใช้สูตรดึงชื่อสินค้าและราคาจากตารางรหัสสินค้า Master Table

=VLOOKUP(F2, $A$2:$C$5, 2, FALSE)
A (Col 1) B (Col 2 - Target) C (Price) Result (G2)
SKU-01 Mechanical Keyboard ฿2,500 Ergonomic Mouse
SKU-02 ✓ Ergonomic Mouse ฿1,200

การทำงาน:

1. ค้นหาค่า "SKU-02" ในคอลัมน์แรก (A)
2. เมื่อพบในแถวที่ 2 จะดึงค่าในคอลัมน์ที่ 2 (B) มาแสดงผลได้ "Ergonomic Mouse"

Change index from 2 to 3 to retrieve the price (฿1,200) instead.

Lookup Functions

XLOOKUP: The Next-Gen Lookup Standard

ค้นหาทางซ้ายหรือขวาได้ โดยแยกช่วงค้นหาและช่วงผลลัพธ์ให้มีขนาดสอดคล้องกัน

=XLOOKUP(search_key, lookup_range, result_range, [missing_val])

search_key: ค่าที่ต้องการค้นหา

lookup_range: คอลัมน์ที่เก็บค่าค้นหา (คอลัมน์เดี่ยว)

result_range: คอลัมน์ผลลัพธ์ (อยู่ซ้ายหรือขวาก็ได้!)

missing_val: ค่าที่แสดงหากหาไม่เจอ เช่น "Not Found"

MAJOR ADVANTAGES
  • ค้นหาย้อนกลับไปทางซ้ายได้ (Left Lookup)
  • ไม่ต้องนับ index แทรกคอลัมน์สูตรไม่พัง
  • ค่าเริ่มต้นคือ Exact Match อัตโนมัติ
  • มีดักจับ Error ในตัว
XLOOKUP is the recommended modern lookup standard for Google Sheets.

Practical Workshop

XLOOKUP Left-Lookup Demonstration

ตัวอย่างการค้นหาข้อมูลแบบดึงค่ากลับมาทางซ้าย (สิ่งที่ VLOOKUP ทำไม่ได้)

=XLOOKUP(E2, B2:B5, A2:A5, "Not Found")
A (Target Left) ⬅ B (Lookup Key) Email Input EmpID Output
EMP-102 ✓ wichai@co.th wichai@co.th EMP-102

พลังของ Left Lookup:

เรามี Email ในคอลัมน์ B แต่อยากได้รหัส EmpID ในคอลัมน์ A ซึ่งอยู่ทางซ้ายมือ XLOOKUP สามารถดึงข้ามมาทางซ้ายได้ทันทีโดยไม่ต้องย้ายตำแหน่งคอลัมน์จริง

If the email does not exist, it cleanly returns "Not Found" without #N/A.

Lookup Functions

INDEX & MATCH: The Flexible Architecture

คู่หูฟังก์ชันพิกัดเมทริกซ์ 2 มิติที่ทำงานได้รวดเร็วและรองรับตารางข้อมูลขนาดใหญ่

1. INDEX(range, row, [col])

ระบุพิกัดแถวและคอลัมน์ เพื่อดึงข้อมูล ณ จุดตัดนั้นกลับมา

=INDEX(B2:B10, 3) ➔ ดึงค่าในแถวที่ 3

2. MATCH(search_key, range, 0)

ค้นหาค่าและคืนผลลัพธ์เป็น "ลำดับเลขที่แถว" ที่พบข้อมูล

=MATCH("Bangkok", A2:A10, 0) ➔ ส่งเลขแถวกลับมา
Together, MATCH finds the row number and feeds it into INDEX.

Practical Workshop

INDEX + MATCH Combined in Action

การประกอบร่าง: MATCH หาเลขแถว แล้วส่งต่อให้ INDEX ดึงข้อมูลที่ต้องการ

=INDEX(C2:C5, MATCH(F1, A2:A5, 0))
A (Match Range) B (Name) C (Salary) Result
ID-03 (Row 3) ✓ Nonglak ฿55,000 ฿55,000
HOW IT WORKS

1. MATCH("ID-03", A2:A5, 0) ได้ผลลัพธ์เป็นแถวที่ 3
2. INDEX นำเลข 3 ไปดึงค่าใน C2:C5 ได้เงินเดือน ฿55,000

INDEX-MATCH works in all spreadsheet software and handles 2D matrix lookups.

Filtering Functions

FILTER: Dynamic In-Sheet Data Slicing

การกรองข้อมูลแบบไดนามิกที่ดึงหลายแถวและหลายคอลัมน์ออกมาแสดงผลพร้อมกัน

=FILTER(range, condition1, [condition2, ...])

range: ช่วงข้อมูลต้นทางที่ต้องการกรอง (A2:D100)

condition1: เงื่อนไขแบบ Boolean เช่น C2:C100 = "Completed"

Multiple: คั่นด้วยคอมมา (AND) หรือเครื่องหมาย + (OR)

ARRAY SPILL

Spill Behavior

พิมพ์สูตรเพียงเซลล์เดียวที่มุมซ้ายบน ผลลัพธ์จะกระจาย (Spill) ออกมาเต็มพื้นที่อัตโนมัติ ห้ามมีข้อมูลอื่นขวางทางเดินมิฉะนั้นจะขึ้น #REF!

ข้อมูลต้นทางเปลี่ยน ตารางผลลัพธ์จะอัปเดตตามทันที

Remember: Empty cells around the spill zone must be clear of obstructions.

Practical Workshop

FILTER with Multiple Conditions

การทดลองกรองออเดอร์ยอดขายเฉพาะโซน Bangkok ที่มียอดเงินมากกว่า 50,000 บาท

=FILTER(A2:C5, B2:B5="Bangkok", C2:C5>50000)
OrderID Region Amount (THB)
SO-103 Bangkok ฿145,000

Condition Filtering:

SO-101 ถูกตัดออกเพราะ Amount ไม่ถึง 50,000
SO-102 ถูกตัดออกเพราะ Region คือ Chiang Mai
ผลลัพธ์จึงได้เฉพาะแถว SO-103 ที่ตรงครบทั้ง 2 เงื่อนไข

Wrap with =IFNA(FILTER(...), "No Data") to handle zero matches gracefully.

Advanced Querying

QUERY: SQL-Like Data Manipulation

ฟังก์ชันที่ทรงพลังที่สุดใน Google Sheets ด้วยคำสั่งประมวลผลคล้ายภาษา SQL

=QUERY(data, "SELECT ... WHERE ... ORDER BY ...", [headers])

SELECT: ระบุคอลัมน์ที่ต้องการเลือก (SELECT A, B, D)

WHERE: เงื่อนไขคัดกรอง (WHERE C >= 1000)

ORDER BY / LIMIT: เรียงลำดับและจำกัดแถว

ALL-IN-ONE

จบในฟังก์ชันเดียว

แทนที่จะเขียน FILTER ซ้อน SORT ซ้อน UNIQUE... ฟังก์ชัน QUERY สามารถกรอง รวมกลุ่ม (GROUP BY) และจัดเรียงข้อมูลได้ครบในคำสั่งเดียว

นิยมใช้ทำ Dashboard ระดับผู้บริหาร

Remember that QUERY column letters must be uppercase (e.g. SELECT A, B).

การเขียนสูตร QUERY สรุปผลรวมยอดขายแยกตามหมวดหมู่สินค้า

=QUERY(A1:F5, "SELECT D, SUM(F) GROUP BY D", 1)
Category (D) Total Sales

คำอธิบาย:

• GROUP BY D: รวมกลุ่มตามชื่อหมวดหมู่
• SUM(F): หาผลรวมยอดเงินของแต่ละกลุ่ม
สร้างผลลัพธ์แบบ Pivot Table อัตโนมัติในเซลล์เดียว

QUERY recalculates live whenever source data updates.

Data Reshaping

VSTACK & HSTACK: Seamless Table Merging

การรวมตารางจากหลายชีทหรือหลายสาขามาต่อกันในแนวตั้งและแนวนอนโดยอัตโนมัติ

VSTACK (Vertical)

นำตารางมาต่อกันในแนวตั้ง (ต่อท้ายแถวลงมา)

=VSTACK(BranchA!A2:C, BranchB!A2:C)

HSTACK (Horizontal)

นำคอลัมน์มาวางเคียงข้างกันในแนวนอน (ต่อขวา)

=HSTACK(A2:A10, D2:D10)
Perfect for consolidating monthly reports from different branch tabs.

Data Reshaping

TOCOL & TOROW: Matrix Flattening

การแปลงตาราง 2 มิติ (Matrix) ให้กลายเป็นคอลัมน์เดียวหรือแถวเดียวในพริบตา

=TOCOL(range, [ignore])

บีบอัดตารางหลายคอลัมน์ให้เรียงเป็น 1 คอลัมน์เดี่ยว

=TOCOL(A2:D10, 1) (ใส่ 1 ข้ามช่องว่าง)

=TOROW(range, [ignore])

บีบอัดตารางทั้งหมดให้แผ่ขยายออกเป็น 1 แถวแนวนอน

=TOROW(A2:C5, 3) (ใส่ 3 ข้ามช่องว่าง & Error)
Use TOCOL to flatten survey responses and multi-column attendee lists.

Regular Expressions

The Regex Trio: Pattern Intelligence

ชุดฟังก์ชัน Regular Expressions สำหรับจัดการข้อความที่มีรูปแบบพิเศษ

REGEXMATCH

ทดสอบว่าข้อความตรงกับ Pattern หรือไม่

=REGEXMATCH(A2, "\d{10}")

คืนค่า: TRUE / FALSE

REGEXEXTRACT

ดึงเฉพาะคำหรือตัวเลขตาม Pattern ออกมา

=REGEXEXTRACT(A2, "[A-Z]+")

คืนค่า: ข้อความที่ดึงได้

REGEXREPLACE

ค้นหาและแทนที่ข้อความตาม Pattern

=REGEXREPLACE(A2, "\D", "")

คืนค่า: ข้อความที่แปลงแล้ว

Common token: \d = digits; \D = non-digits; [A-Z] = uppercase letters.

Aggregations

The SUM Evolution: SUM vs SUMIF vs SUMIFS

วิวัฒนาการของฟังก์ชันผลรวม: รวมทั่วไป, รวมแบบเงื่อนไขเดียว, และรวมหลายเงื่อนไข

SUM

=SUM(D2:D100)

บวกตัวเลขทุกตัวในช่วง ไม่มีเงื่อนไข

รวมทุกแถว

SUMIF (1 Cond)

=SUMIF(A:A, "TH", C:C)

ช่วงบวก (sum_range) อยู่ตำแหน่งสุดท้าย

บวกแบบเงื่อนไขเดียว

SUMIFS (Multi)

=SUMIFS(C:C, A:A, "TH")

ช่วงบวก (sum_range) อยู่ตำแหน่งแรกสุด!

บวกแบบหลายเงื่อนไข

Critical syntax rule: In SUMIFS, sum_range is the FIRST parameter!

Defensive Formulas

Defensive Design: IFERROR Shielding

การดักจับข้อผิดพลาดของสูตรเพื่อป้องกันหน้าต่างรายงานขึ้น #N/A หรือ #DIV/0!

=IFERROR(formula_expression, value_if_error)
ไม่มี IFERROR: VLOOKUP หาไม่เจอจะขึ้น #N/A แดงทั้งชีท
ก่อนใช้ IFERROR: ตรวจสาเหตุ แล้วเลือกข้อความที่ไม่ทำให้เข้าใจผิดว่าเป็นศูนย์จริง
BEST PRACTICE

สูตรหารตัวเลข

=IF(B1=0, "ยังคำนวณไม่ได้", A1/B1)

แยกกรณีตัวหารเป็นศูนย์ออกจากผลคำนวณศูนย์จริง ตรวจตัวเลขก่อนนำไปสรุปรายงาน

กรณีหาไม่พบอาจใช้ IFNA; IFERROR จับข้อผิดพลาดหลายชนิดและอาจซ่อนสูตรผิด

ทดสอบข้อมูลปกติ ข้อมูลว่าง และค่าที่หาไม่พบ ก่อนกำหนดผลลัพธ์สำรอง

Advanced Functional

LAMBDA: Custom Reusable Functions

การสร้างฟังก์ชันเฉพาะตัวขึ้นมาใช้เองโดยไม่ต้องเขียน Google Apps Script

=LAMBDA(price, vat, price * (1 + vat))(1000, 0.07)

1. Parameters: กำหนดตัวแปรรับค่า (price, vat)

2. Logic: สมการคำนวณ price * (1 + vat)

3. Arguments: ส่งค่าจริงต่อท้ายเพื่อคำนวณ

NAMED FUNCTIONS

บันทึกเป็นชื่อฟังก์ชันประจำองค์กร

นำสูตร LAMBDA ไปบันทึกใน Data > Named functions เพื่อสร้างฟังก์ชันชื่อ =CALC_VAT(A1) ให้ทุกคนในทีมเรียกใช้ได้ทันที

เปลี่ยนสูตรซับซ้อนให้กลายเป็นคำสั้นๆ ที่เข้าใจง่าย

LAMBDA powers array helper functions like MAP, BYROW, and SCAN.

Formula Optimization

LET: In-Formula Variable Assignment

การประกาศตัวแปรภายในสูตร เพื่อเพิ่มความเร็วในการคำนวณและลดการเขียนสูตรซ้ำ

=LET(price, VLOOKUP(A2, Table, 2, 0), IF(price > 1000, price * 0.9, price))

คำนวณ VLOOKUP เพียงครั้งเดียว เก็บไว้ในตัวแปร price แล้วนำไปใช้ต่อใน IF ได้ทันที

KEY BENEFITS
  • เร็วขึ้นอย่างมหาศาล: ชีทไม่ต้องดึง VLOOKUP ซ้ำ
  • สูตรสั้นลง: อ่านง่ายและ Debug สะดวก
  • แก้ไขจุดเดียว: แก้ไขค่าที่ตัวแปรเพียงแห่งเดียว

เครื่องมือสำคัญสำหรับสเปรดชีตขนาดใหญ่

Use LET to dramatically speed up sluggish workbooks with heavy lookup formulas.

Advanced Functional

MAP: Array Iteration with LAMBDA

ประมวลผลช่วงข้อมูลทีละค่าด้วย LAMBDA ยืดหยุ่นกว่า ARRAYFORMULA แบบเดิม

=MAP(B2:B3, C2:C3, LAMBDA(qty, price, qty * price))
Item Qty (B) Price (C) Result
Product A 2 1500 ฿3,000
Product B 3 1500 ฿4,500

การทำงาน:

เขียนสูตรเพียงเซลล์เดียวที่แถวบนสุด MAP จะส่งค่าแต่ละคู่เข้าไปคูณใน LAMBDA และกระจายผลลัพธ์ลงมาให้ครบทุกแถวอัตโนมัติ

MAP overcomes the historic limitations of ARRAYFORMULA with logical AND/OR statements.

Advanced Tools

Regular Expression (Regex) คืออะไร?

ชุดคำสั่งสัญลักษณ์ที่ใช้ค้นหา ตรวจสอบ และจัดการกับข้อความตาม "รูปแบบ (Pattern)" ที่เราต้องการ

สัญลักษณ์พื้นฐาน (Basic Symbols)

  • ^ จุดเริ่มต้นของข้อความ
  • $ จุดสิ้นสุดของข้อความ
  • . แทนตัวอักษรใดๆ ก็ได้ 1 ตัว
  • \d ตัวเลข 0-9 (Digit)
  • \w ตัวอักษร, ตัวเลข, หรือ _ (Word)

สัญลักษณ์บอกจำนวน (Quantifiers)

  • * มีหรือไม่มีก็ได้ (0 หรือมากกว่า)
  • + ต้องมีอย่างน้อย 1 ตัว (1 หรือมากกว่า)
  • ? มีหรือไม่มีก็ได้แค่ 1 ตัว (0 หรือ 1)
  • [] เลือกตัวใดตัวหนึ่งในวงเล็บ เช่น [A-Z]
  • () จัดกลุ่ม (Group) สัญลักษณ์

Regex Function

REGEXMATCH (ตรวจสอบเงื่อนไข)

ใช้คืนค่า TRUE / FALSE เมื่อข้อความนั้นตรงกับ Pattern ที่กำหนด นิยมใช้กับ Data Validation หรือ IF

Syntax: =REGEXMATCH(text, regular_expression)

Example 1: ตรวจสอบว่าในข้อความมี "ตัวเลข" ผสมอยู่หรือไม่?

=REGEXMATCH("Order123", "\d+") TRUE

Example 2: ตรวจสอบว่าขึ้นต้นด้วย "TH" และตามด้วยตัวเลข 4 ตัว

=REGEXMATCH("TH2024-X", "^TH\d{4}") TRUE

Regex Function

REGEXEXTRACT (ดึงข้อมูลจำเพาะ)

ใช้สกัดข้อความ (Extract) ส่วนที่ตรงกับ Pattern ออกมาจากประโยคยาวๆ

Syntax: =REGEXEXTRACT(text, regular_expression)

Example 1: ดึงเฉพาะ "ตัวเลข" ออกจากรหัสผสม

=REGEXEXTRACT("INV-89342-X", "\d+") "89342"

Example 2: ดึง "โดเมนเนม" ออกจากอีเมล โดยใช้กลุ่ม ( )

=REGEXEXTRACT("john@gmail.com", "@(.*)") "gmail.com"

Regex Function

REGEXREPLACE (ค้นหาและแทนที่)

ใช้ลบหรือดัดแปลงข้อความโดยอิงจาก Pattern (เช่น เซ็นเซอร์ข้อมูล, ตัดตัวอักษรพิเศษ)

Syntax: =REGEXREPLACE(text, regular_expression, replacement)

Example 1: เซ็นเซอร์เบอร์โทรศัพท์มือถือ (ปิด 4 ตัวหลัง)

=REGEXREPLACE("0891234567", "\d{4}$", "****") "089123****"

Example 2: ลบอักขระพิเศษทั้งหมดออกให้เหลือแต่ตัวอักษรและตัวเลข

=REGEXREPLACE("Data@# 2024!", "[^\w\s]", "") "Data 2024"

Regex Usecases

Real-world Regex: Data Validation (การตรวจสอบข้อมูล)

ตัวอย่างการใช้งานจริงเพื่อตรวจสอบความถูกต้องของข้อมูล (Data Integrity) โดยใช้ REGEXMATCH

1. ตรวจรูปแบบเลข 13 หลัก (ข้อมูลสมมติ)

ต้องเป็นตัวเลข \d จำนวน 13 ตัวเป๊ะๆ ตั้งแต่ต้น ^ จนจบ $

=REGEXMATCH(A2, "^\d{13}$") "1100112233445" ➔ TRUE

2. ตรวจรูปแบบเลข 10 หลักที่ขึ้นต้นด้วย 0

ต้องขึ้นต้นด้วยเลข 0 และตามด้วยตัวเลขอีก 9 หลัก รวมเป็น 10 หลัก

=REGEXMATCH(A2, "^0\d{9}$") "0891234567" ➔ TRUE

3. ตรวจสอบรูปแบบอีเมล (Email Format)

ตรวจสอบการมีสัญลักษณ์ @ และ . (dot) โดยใช้กลุ่มตัวอักษร \w (Word) และอักขระพิเศษ

=REGEXMATCH(A2, "^[\w\.-]+@[\w\.-]+\.[a-zA-Z]{2,}$") "test@gmail.com" ➔ TRUE

Regex Usecases

Real-world Regex: Extraction & Replace

ประยุกต์ใช้กลุ่ม (Group) ควบคู่กับ REGEXEXTRACT และการจัดโครงสร้างข้อความใหม่ด้วย REGEXREPLACE

1. สกัดรหัส Tracking จากข้อความยาวๆ (REGEXEXTRACT)

ใช้ () Capture Group เพื่อดึงข้อมูลเฉพาะส่วนที่ต้องการออกมา เช่น ตัวอักษรและเลขที่ตามหลังคำว่า "Tracking:"

Text: "Your order has been shipped. Tracking: TH123456789. Thank you!"
=REGEXEXTRACT(A2, "Tracking:\s([A-Z0-9]+)") "TH123456789"

2. จัดรูปแบบวันที่ใหม่ด้วย Backreferences (REGEXREPLACE)

ใช้กลุ่ม () จับข้อมูลเป็นส่วนๆ และอ้างอิงกลับด้วย $1, $2, $3 เพื่อสลับตำแหน่งการแสดงผล

Text: "31/12/2024" (DD/MM/YYYY) ➔ ต้องการเปลี่ยนเป็น "2024-12-31" (YYYY-MM-DD)
=REGEXREPLACE(A2, "(\d{2})/(\d{2})/(\d{4})", "$3-$2-$1") "2024-12-31"
